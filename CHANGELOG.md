# Changelog

All notable changes to Prefab Diff Checker will be documented here.

## \[1.0.0\]

### Added

-   Side-by-side prefab comparison inside the Unity Editor
-   Compare local prefabs against Git revisions
-   GameObject, Component and serialized property comparison
-   Added, removed, modified and moved change detection
-   Smart matching for renamed, reordered and moved GameObjects
-   Change filtering and navigation
-   Read-only Git integration
